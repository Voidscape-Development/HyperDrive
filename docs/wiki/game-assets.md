# Game assets

Game assets are each game's character icons, portraits and stages. They're what lets you
pick characters on the scoreboard and what the layouts show.

## Downloading assets

Open ☰ › [Download assets](hyperdrive://open/download-assets). Games you have packs for
are listed first. The search box finds games and packs by name or description, and
**Installed** and **Updates** narrow the list.

Pick a game, tick the packs you want, and click **Download**. Each pack lists its size,
whether it includes stage and eyesight data, a description and its credits (hover over a
pack to read them in full). A game's *Base files* hold its characters and stages: every
other pack needs them, so they're added for you when you pick a pack of a game you don't
have yet. You can tick packs of several games before downloading.

Downloads run one after the other in the **Downloads** panel at the bottom of the window,
with their progress and time left. Cancel one with ✕, or try a failed one again with
**Retry**. HyperDrive stays usable meanwhile, and downloads keep going if you close the
window.

A pack with a newer version shows **Update available** and an **Update** button.
**Review updates** lists every update with its size, to untick any you'd rather skip
before updating. ⋯ on an installed pack opens its folder or removes it.

When a pack of the game you're using has an update, ☰ › **Download assets** gets a badge.
Without a connection, the window shows the packs you already have.

Packs go in `user_data/games/<game>/`. The assets come from the community
[StreamHelperAssets](https://github.com/joaorb64/StreamHelperAssets/) database: to add a
game or fix a character, contribute there (☰ › **Help** › **Contribute to the Asset
Database**).

## Picking the game

The game dropdown at the top of the window picks the game; it's set for you when a
start.gg event is loaded. Type to filter it. ⟳ reloads the game's assets, e.g. after adding
files by hand.

Games with modded characters show a **Modded content** checkbox to include them.

## Languages

Character and stage names follow ☰ › **Game Asset Language**, which can differ from
HyperDrive's own language.

## Character select

The scoreboard's character grid shows the player's mains and recently picked characters on
top. Turn those rows off in
[Settings › Character Select](hyperdrive://open/settings/character-select).
