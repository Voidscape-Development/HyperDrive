# Game assets

Game assets are each game's character icons, portraits and stages. They're what lets you
pick characters on the scoreboard and what the layouts show.

## Downloading assets

Open ☰ › [Download assets](hyperdrive://open/download-assets). Pick the game, then the
asset packs you want (e.g. *base_files* for the icons, and packs of full art or renders),
and click **Download**. Each pack lists its size, whether it includes stage and eyesight
data, a description and its credits. **Update all** updates every installed pack whose
version is out of date.

When a pack of the game you're using has an update, ☰ › **Download assets** gets a badge.

Packs go in `user_data/games/<game>/`. The assets come from the community
[StreamHelperAssets](https://github.com/joaorb64/StreamHelperAssets/) database: to add a
game or fix a character, contribute there (☰ › **Help** › **Contribute to the Asset
Database**).

## Picking the game

The game dropdown at the top of the window picks the game; it's set for you when a
start.gg event is loaded. Type to filter it. ⟳ reloads the game's assets, e.g. after adding
files by hand.

Games with modded characters show a **Modded content** checkbox to include them.

## Languages

Character and stage names follow ☰ › **Game Asset Language**, which can differ from
HyperDrive's own language.

## Character select

The scoreboard's character grid shows the player's mains and recently picked characters on
top. Turn those rows off in
[Settings › Character Select](hyperdrive://open/settings/character-select).
