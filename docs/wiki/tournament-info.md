# Tournament info

The [Tournament Info](hyperdrive://open/tournament-info) tab holds what the layouts show
about the event itself:

| Field | |
| - | - |
| **Tournament Name**, **Event Name** | Shown on scoreboards, brackets and top 8s |
| **Address**, **Date** | Where and when |
| **Entrant Number** | How many entrants |
| **Short Link** | e.g. the start.gg short link for viewers |
| **Tournament Icon** | The logo. **Download tournament icon** takes it from start.gg, **Load local file** uses an image of yours, **Default** goes back to the default |

**Load from tournament** fills it all in from the loaded [tournament](tournaments.md). It's
filled in when an event is loaded, and you can change anything afterwards. **Clear**
empties it.

The tournament's logo and banner from start.gg are also sent to the layouts
(`tournamentInfo.logo` and `tournamentInfo.banner`).
