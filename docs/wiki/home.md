# Welcome to HyperDrive

HyperDrive is a stream helper for fighting game tournaments. It loads sets, players and
brackets from your tournament and sends them to HTML overlays (*layouts*) that you add to
OBS, or any other streaming software, as browser sources.

New to HyperDrive? Start with **[Getting started](getting-started.md)**: it takes you
from a fresh install to a scoreboard on stream in a few minutes.

## Using this guide

- Use the **search box** at the top to find any word in the guide. Press Enter to open the
  first result.
- Links in **bold accent color** like [Open the settings](hyperdrive://open/settings)
  open that part of HyperDrive for you.
- **Back** and **Forward** work like in a browser (Alt+Left and Alt+Right).
- The guide is also served by HyperDrive's web server at `http://<HyperDrive's address>:5500/wiki`,
  so you can read it on a phone or a second screen while you work.

You can open this guide at any time from the menu button (☰) › **Help** › **Guide**.
