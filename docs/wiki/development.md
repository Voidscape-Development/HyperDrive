# Development

HyperDrive is a Python and Qt (PyQt6) application, with a FastAPI and socket.io web server,
HTML layouts, and a React app for the phone pages. Its source code is on
[GitHub](https://github.com/Voidscape-Development/HyperDrive).

## Running from source

HyperDrive uses [uv](https://docs.astral.sh/uv/), which installs Python and the dependencies
locked in `uv.lock`:

```sh
uv run main.py
```

`HyperDrive.sh` (Linux and macOS) and `HyperDrive.bat` (Windows) do the same. The Windows
executable is built with Python 3.10, so the code has to stay compatible with it.

## Checks

```sh
uv run ruff check .    # lint
uv run ruff format .   # format
```

The tests in `test/` are standalone scripts, run from the repository root:

```sh
uv run python test/test_stream_queue.py
```

## The phone pages

The stage strike, character select, remote scoreboard and bracket focus pages are a Vite
app in `stage_strike_app/`. Its build is committed, so rebuild it only if you change it:

```sh
cd stage_strike_app
npm ci
npm run build
```

## Editing this guide

The guide's pages are Markdown files in `docs/wiki/`, one per page; `contents.json` lists the
sidebar's sections and their pages in order. A page's title is its first `# ` heading.

- Link to another page with its file name, e.g. `[Scoreboard](scoreboard.md)`, or a part of
  it with `scoreboard.md#several-scoreboards` (the heading in lowercase, with dashes).
- `hyperdrive://open/<target>` links open part of the app, e.g.
  `hyperdrive://open/settings/api-keys`. The targets are registered in
  `Window.RegisterGuideLinks()` in `src/HyperDrive.py`.
- Translations go in `docs/wiki/<language>/<page>.md` (e.g. `docs/wiki/fr/home.md`).
  Untranslated pages fall back to English.
- `test/test_wiki.py` checks that every page, link and app link exists.

The guide is read by the Guide window (`src/WikiWindow.py`) and served at `/wiki` by the web
server; both use `src/Wiki.py`.
