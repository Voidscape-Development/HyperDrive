# start.gg GraphQL schemas

Local copies of start.gg's GraphQL schemas, to check field names, arguments and
types against when changing the queries HyperDrive sends.

| File | API | Used by |
| --- | --- | --- |
| [`schema.graphql`](schema.graphql) | Internal site API, `https://www.start.gg/api/-/gql` | `StartGGDataProvider` |
| [`public_schema.graphql`](public_schema.graphql) | Public API, `https://api.start.gg/gql/alpha` | `StartGGReporter` |

Both are generated by [`scripts/gen_startgg_schema.py`](../../scripts/gen_startgg_schema.py)
and updated daily by the `Update start.gg schema` workflow, so don't edit them by hand.
Types and fields are sorted alphabetically, so the history of each file shows what
start.gg changed and when.

The public API only allows introspection with a token. The workflow reads one from the
`STARTGG_TOKEN` repository secret; until that secret is set, `public_schema.graphql`
isn't generated.

To regenerate locally:

```sh
uv run scripts/gen_startgg_schema.py
# Also the public API schema:
STARTGG_TOKEN=<your developer token> uv run scripts/gen_startgg_schema.py
```

The internal API isn't documented by start.gg and can change without notice. When a
query breaks, compare `schema.graphql`'s history around that date.
