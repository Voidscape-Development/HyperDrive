Put a folder here for each player or commentator whose custom data the layouts should get,
named after their tag ("Bay_Blade") or their sponsor and tag ("TEAM Bay_Blade"), in any case.
The tag's own folder is used if there's both.

As the following characters (,/|;:<>\?*) are not able to be used in (Windows) file names,
all invalid characters will need to be replaced with an underscore (_) to be recognized as valid for HyperDrive.

Each file in the folder is sent to the layouts by its name without the extension,
e.g. bio.txt as "bio":
- .txt, .md, .html, .csv and .xml files: their text
- .json files: what they hold
- anything else (images, videos...): its path

Changes to the files show up on stream within a second.
It can be turned off in Settings > General.
