As the following characters (,/|;:<>\?*) are not able to be used in (Windows) file names,
all invalid characters will need to be replaced with an underscore (_) to be recognized as valid for HyperDrive.

The image shows up on stream within a second, also for a player already on the scoreboard.

E.x. "Bay|Blade" would equal "Bay_Blade" for the file name

You can also manage these images in HyperDrive: Player database > Player media.
